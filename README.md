# Remind PT

**트레이너를 위한 회원 · 수업 · 정산 통합 관리 웹 애플리케이션**

Remind PT는 여러 근무처에서 활동하는 퍼스널 트레이너가 회원, 이용권, 수업 일정, 운동 기록 및 정산 내역을 하나의 서비스에서 관리할 수 있도록 개발한 개인 프로젝트입니다.

회원 등록부터 수업 운영, 출석 관리, 월별 수입 확인까지 이어지는 업무 흐름을 효율적으로 관리하는 것을 목표로 합니다.

## 프로젝트 개요

- **개발 형태:** 개인 프로젝트 (기획 · 설계 · 프론트엔드 · 백엔드 연동 · 배포)
- **서비스 형태:** 반응형 웹 애플리케이션
- **주요 사용자:** 개인 PT 트레이너 및 여러 근무처에서 활동하는 트레이너
- **배포 환경:** Vercel
- **데이터베이스 및 인증:** Supabase

## 주요 기능

### 1. 대시보드

- 전체 회원 및 활성 이용권 현황
- 오늘의 수업 일정과 상태별 통계
- 월별 수업 현황
- 근무처별 PT · 그룹 수업 통계
- 이용권 잔여 횟수 알림

### 2. 회원 및 이용권 관리

- 회원 등록 · 수정 · 보관
- PT · 그룹 · 멤버십 이용권 관리
- 이용권 이용 현황 및 잔여 횟수 확인
- 회원별 수업 이력과 운동 기록 관리
- 회원 메모 작성 및 조회

### 3. 수업 및 출석 관리

- PT · 그룹 수업 예약
- 수업 일정 및 참여 회원 관리
- 출석 · 노쇼 · 당일 취소 · 일반 취소 처리
- 출석 상태에 따른 이용권 차감 정책 적용
- 이전 운동 기록을 참고한 수업 기록 작성

### 4. 근무처 및 정산 관리

- 근무처별 PT · 그룹 수업 단가 설정
- 날짜별 단가 변경 이력 관리
- 근무처별 노쇼 · 당일 취소 정산 포함 여부 설정
- 수업 날짜에 적용되는 단가와 정책을 이용한 월별 정산 자동 계산
- 확정 및 예정 정산액 구분
- 수업별 정산 상세 내역 조회
- 월별 정산 요약 및 상세 내역 Excel 다운로드

### 5. 데모 체험

- 별도의 회원가입 없이 서비스 체험
- 실제 사용자 데이터와 분리된 샘플 데이터 제공
- 주요 회원 · 수업 · 정산 관리 화면 탐색
- 데모 환경에서 입력 및 저장 흐름 체험 (실제 서버 데이터 변경 방지)

## 주요 기술적 설계

### 서버 상태와 클라이언트 상태 분리

TanStack Vue Query를 이용해 서버 데이터 조회, 캐싱 및 갱신을 관리하고, Pinia를 활용해 클라이언트 상태를 관리하도록 구성했습니다.

### 날짜별 이력 기반 정산 계산

근무처별 수업 단가와 정산 정책은 적용 시작일을 기준으로 이력을 관리합니다.

정산 금액 계산 시 현재 설정값만 사용하는 것이 아니라 **실제 수업 날짜에 유효했던 단가와 정책**을 조회하도록 설계했습니다.

PT 수업은 회당 단가, 그룹 수업은 회원별 참여 단가를 기준으로 계산합니다.

### 데이터 접근 제어

Supabase Auth를 활용한 인증 기능과 PostgreSQL RLS(Row Level Security)를 적용하여 사용자별 데이터 접근을 제어하도록 설계했습니다.

정산 계산 및 회원 등록과 같은 데이터 처리에는 Supabase RPC를 활용했습니다.

### 데모 환경 분리

포트폴리오 방문자가 실제 사용자 데이터에 접근하지 않고 기능을 체험할 수 있도록 별도의 데모 계정과 샘플 데이터를 구성했습니다.

데모 환경에서는 사용자 입력 흐름을 체험할 수 있지만, 실제 서버 데이터가 변경되지 않도록 제한합니다.

### 반응형 인터페이스

데스크톱, 태블릿, 모바일 환경을 고려하여 화면을 구성하고, 데스크톱 사이드바 접기·펼치기와 모바일 탐색 기능을 제공합니다.

## 로컬 개발

```bash
npm install
npm run dev
```

프로덕션 빌드:

```bash
npm run build
```

로컬 실행에는 Supabase 환경 변수 및 프로젝트에 필요한 데이터베이스 스키마, RLS 정책, RPC 함수 설정이 필요합니다.

## 프로젝트 구조

```text
src/
├── api/             # Supabase 데이터 조회 및 처리
├── components/      # 기능별 재사용 컴포넌트
├── layouts/         # 공통 레이아웃
├── router/          # 라우팅 및 인증 확인
├── stores/          # Pinia 상태 관리
├── utils/           # 날짜 및 Excel 다운로드 유틸리티
└── views/           # 페이지 컴포넌트
```

## 프로젝트 목적

Remind PT는 프론트엔드 개발자로서 단순한 UI 구현을 넘어 **실제 사용자의 업무 흐름을 고려한 서비스 설계와 구현 경험**을 확장하기 위해 진행한 개인 프로젝트입니다.

회원 관리, 수업 운영, 출석 정책, 단가 이력 및 정산 계산 등 서로 연결된 데이터를 일관성 있게 처리하는 데 중점을 두었습니다.
